  alerts the fighters within 32 blocks. Villagers hold their `defaultweapon`, which they do not drop.
  Hurting a peaceful villager costs 10 reputation per point of damage, killing one 500.
- Population: mothers whose type has `malechild`/`femalechild` have a child when a man lives in the house and
  it has room; children grow for three game days and then take a free adult place of their gender in the

  `/millenaire village populate` and `/millenaire villager growup` run these steps at once.

  `collectgood` drops, minding the stall, visiting the inn and other buildings, breeding and shearing,
  sugar cane and fishing.
- Plan audit: all 1811 plans are placeable. Village commands load the chunks under the layout; villages are
  lifted when their basements would reach the world floor.

## Content inspection commands

- `/millenaire content stats` reports catalog counts and diagnostics.
- `/millenaire content reload` atomically replaces the catalog after reading bundled and custom files.
- `/millenaire quest list [group]` lists validated quests; `/millenaire quest info worldquest-indian/sadhu_intro` shows villagers, steps, English labels, goods and rewards.
- `/millenaire village types norman` lists declared village types and their starting buildings.
- `/millenaire building info norman:fountain_A0` decodes a plan and reports its dimensions and service point counts.
- /millenaire building check 0 norman:fountain_A0 checks palette conversion and world limits for rotation 0 (allowing terrain replacement for the check).
- /millenaire building place 0 norman:fountain_A0 places into empty or replaceable space.
- /millenaire building replace 0 norman:fountain_A0 explicitly replaces occupied terrain, while preserving existing block entities and bedrock.
- /millenaire building list lists persisted placement records.

The command source position is the building origin; the plan's startlevel sets the floor offset. Rotations are 0..3. Plans are limited to 32,768 cells per operation. These commands do not automatically create villagers or generate a complete settlement.

## Manual starting-layout commands

- `/millenaire village plan 1234 norman:agricole` lists selected starting plans, positions, rotations, and conversion blockers without checking terrain or changing the world.
- `/millenaire village check 1234 norman:agricole` additionally checks placement into empty or replaceable space.
- `/millenaire village checkreplace 1234 norman:agricole` checks explicit terrain replacement without changing blocks.
- `/millenaire village place 1234 norman:agricole` places a fully supported group into empty or replaceable space.
- `/millenaire village replace 1234 norman:agricole` explicitly replaces terrain for a fully supported group; block entities, bedrock, unloaded chunks, and existing saved groups are protected.
- `/millenaire village settlements` lists successful saved groups.
- `/millenaire village lifecycle` lists population, capacity, resources, reputation, and queued projects for the current dimension. `/millenaire village lifecycle add <food> <materials>` adds test resources to the settlement containing the command source; `/millenaire village lifecycle queue <project> <plan> <work> <materials>` queues a construction project for that settlement.

The same type, seed, origin, and content snapshot yield the same layout. The origin uses command height plus each plan's altitude offset; no terrain height scan, foundation extension, road network, residents, or active village simulation is included. Limits: 64 buildings, radius 256, 32,768 cells per building, and 131,072 block operations per group. The bundled Norman agricultural type is suitable for inspecting the layout, but its unported walls and building special points still block placement. See [VILLAGE_PORT_REPORT.md](VILLAGE_PORT_REPORT.md).

The source bundle has one orphan PNG at `cultures/mayan/buildings/core/mayanacropolis_A0.png` without adjacent metadata. It is reported and excluded from the index; the complete townhall version and its upgrades are indexed normally. This source discrepancy is also present in the recovered JAR, while Public-master contains only the townhall version.
