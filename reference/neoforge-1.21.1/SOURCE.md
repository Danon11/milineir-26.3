# NeoForge 1.21.1 reference

Java sources from the `Millenaire-main` NeoForge 1.21.1 fork (see README.md and LICENSE here).
They are kept only as a migration reference: unlike the decompiled Forge 1.12.2 code, this
fork already uses modern Minecraft names (data components, `Level`, `BlockState`, etc.),
which makes it the closest existing implementation for villagers, goals, GUIs and networking.
Resources are not copied; the Fabric project's `src/main/resources` is canonical.
